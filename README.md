# 🎯 Estudos - Técnico em Desenvolvimento de Sistemas (SENAI)

Este repositório foi criado para centralizar todos os exercícios, desafios e projetos realizados durante o curso técnico no **SENAI**.

### 📂 O que tem aqui?

* Atividades e aplicações **Full-Stack Mobile** com React Native e Node.js.
* Atividades e aplicações **Frontend** com React, HTML, CSS e Bootstrap.
* Atividades e aplicações **Backend** com Python + Flask.
* Projetos de **IoT e Automação** com Arduino.
